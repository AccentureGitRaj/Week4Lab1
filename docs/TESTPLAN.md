## Notes for Node.js Test Conversion

- Candidate unit-test targets: menu choice routing, credit arithmetic, debit rules, insufficient-funds branch, data read/write behavior.
- Candidate integration-test targets: full menu-to-operation-to-storage flow for each option.
- Keep display-format assertions tolerant for leading zeros in COBOL output, while asserting numeric value equivalence.
